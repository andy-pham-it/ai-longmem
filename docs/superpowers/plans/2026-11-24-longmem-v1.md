# longmem v1 — hybrid recall (FTS + trigram) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `/recall` and `/related` rank by meaning (Postgres full-text search) in addition to fuzzy word overlap (trigram), with no external model, no new endpoint, and no change to the response shape.

**Architecture:** Add a trigger-maintained `search_vector tsvector` column plus a GIN index; backfill existing rows; rewrite `longmem_search` to combine `ts_rank` (FTS) with `similarity` (trigram) plus `reinforced_count` and `pinned` boosts. `'simple'` config (no stemming) for mixed-language safety. Weights are SQL constants.

**Tech Stack:** Supabase Postgres 17 (pg_trgm, unaccent, built-in FTS), Deno Edge Function (unchanged), Vitest (no new tests — scoring lives in SQL, verified by `supabase db query`).

**Spec:** `docs/superpowers/specs/2026-11-24-longmem-v1-design.md` (§3 data model, §4 scoring, §6 migration).

## Global Constraints

- No external model, no new secret, no new endpoint, no new CLI command.
- Response shape of `/recall` and `/related` is unchanged (entries + total).
- `/index`, 8 KB budget, plugin, sensitive semantics unchanged.
- Migration numbering continues: `0004_fts_recall.sql`.
- All hosted SQL runs via `supabase db query --remote -f <file> --yes` (no direct DB URL).
- Verify script must end with every result starting `ok`.

## Review Focus

- A query with no shared words with any entry must still return the best available match rather than an empty list (recall is forgiving).
- The GIN index must exist on `search_vector` or FTS degrades to a seq scan at scale.
- `memories_touch` must keep `search_vector` in sync on both insert and update (a reworded entry must be findable by its new words).
- Backfill must populate `search_vector` for the 7 seeded entries, not leave them as empty vectors.
- `/related` must score trigger-only, so a long body cannot drown a short trigger match.
